# PW Calculator · Comeback 1.4.6

Локальный калькулятор персонажа Perfect World с интерфейсом по образцу
[mypers.ru](https://mypers.ru/). Использует 10 классов и данные Comeback PW 1.4.6:
Воин, Маг, Оборотень, Друид, Лучник, Жрец, Мистик, Страж, Шаман, Убийца.

## Запуск

При первом запуске установить Python-зависимости через `uv sync --frozen`.
Затем дважды щёлкнуть `Запустить сайт.bat`.

Можно запустить уже подготовленное окружение напрямую:

```powershell
.venv\Scripts\python.exe -m tools.serve --port 8002
```

Сервер слушает только локальный компьютер. Окно сервера нужно оставить открытым.

## Возможности

- Класс, пол, имя, уровень и распределение очков характеристик.
- Числовая репутация и требования вещей: вещь можно выбрать заранее; красные требования отключают её бонусы до выполнения условий.
- Собственные портреты и наборы бафов для каждого класса; у Мистика и Стража доступны оба пола.
- Уровни бафов, светлые/тёмные варианты, отдельные состояния и девять бонусов титулов.
- Компактный поиск экипировки с фильтрами и игровыми подсказками; выбор сразу надевает вещь.
- Отдельный редактор подтверждённой заточки, камней и точных значений дополнительных свойств.
- Сохранение персонажей в браузере, JSON-файлы и ссылки со сборкой.
- Мобильный интерфейс и локальные изображения; внешние API для расчёта не нужны.

Предметы и камни берутся только из раздела **Comeback `/db/146/`**.
Современный каталог mypers не импортируется. Количество записей и покрытие
категорий указаны в `data/catalog_meta.json` и [отчёте экипировки](docs/equipment-picker-report.html).
Добавлены боеприпасы и трактаты. Каталог остаётся снимком; карточки полётов
собраны не полностью. Наличие записи в базе не доказывает доступность вещи игроку.
Безымянные записи скрыты; по умолчанию выбор ограничен уровнем и классом персонажа.
Постоянные свойства с вероятностью 100% учитываются автоматически, а для
случайных диапазонов можно выбрать точное значение своей вещи.
Поддержанные состояния бафов и дебафов меняют показатели: здоровье, ману,
атаку, защиту, меткость, уклонение, критический удар и скорость. Выбор уровня
умения сам по себе не включает его состояние. Неподдержанные эффекты, включая
часть оружейных мастерств и урон отдельных умений, выводятся в предупреждениях.
Неизвестные свойства предметов, бонусы комплектов, процентные HP/защиты
предметов и неоднозначные значения скорости атаки не заменяются догадками.
Формулы оригинального калькулятора ещё требуют отдельной сверки с игрой Comeback.

## Проверка и отчёт

```powershell
.venv\Scripts\python.exe -m pytest -q
npm.cmd test
.venv\Scripts\python.exe manage.py check
.venv\Scripts\python.exe -m ruff check .
```

[Отчёт HTML](docs/report.html) и [CSV](docs/report.csv) содержат результаты,
снимки экрана и ограничения. HTML открывается самостоятельно без интернета.
[Сверка поведения](docs/behavior-parity.md) отделяет наблюдения на оригинале
от ограничений расчёта.
[Проверка нового выбора экипировки](docs/equipment-picker-report.html) и
[CSV](docs/equipment-picker-report.csv) содержат текущие проверки, покрытие
источников и сверку Метеора по игровому примеру.
[Активация бонусов экипировки](docs/equipment-activation-report.html) и
[CSV](docs/equipment-activation-report.csv) описывают свободный выбор вещей,
включение бонусов после выполнения требований и проверку запущенной копии на порту 8000.
[Предыдущий режим планирования](docs/equipment-planning-report.html) относится
к историческому варианту, в котором считались и бонусы красных вещей.
[Предыдущая проверка репутации](docs/reputation-requirements-report.html) относится
к прежнему строгому режиму, заменённому по уточнению пользователя.

## Обновление снимка

```powershell
.venv\Scripts\python.exe -m tools.scrape.import_cache
```

Команда объединяет ранее собранные страницы и данные в `data/catalog_*.json`.
Работающий сборщик и его `data/items.json` / `data/stones.json` не перезаписываются.
После обновления перезапустить сервер. Метаданные и хеши источников позволяют
проверить происхождение записей. Подробности каталога умений: `tools/mypers/README.md`.

Для пополнения кэша публичными страницами базы и родными иконками:

```powershell
.venv\Scripts\python.exe -m tools.scrape.refresh_public --seconds 1800
.venv\Scripts\python.exe -m tools.scrape.refresh_icons --seconds 300
.venv\Scripts\python.exe -m tools.scrape.import_cache
```

Загрузка использует отдельный браузер и ограниченное время. Если Chromium
для Playwright ещё не установлен, сначала выполнить
`.venv\Scripts\python.exe -m playwright install chromium`.
Готовые файлы публикуются без перезаписи страниц параллельного сборщика.

Панели оформлены в оригинальном стиле тёмного металла и нефрита: объёмный
орнамент, металлические грани и утопленные ячейки. [Описание оформления](docs/jade-panel-design.md)
и [отчёт до/после](docs/jade-design-report.html) содержат детали и проверки.
Портреты, силуэт, игровые иконки и шрифты используют локальные публичные
материалы mypers; происхождение и контрольные суммы — в `static/mypers`.
Чат, мини-окна справа, карты и указанные пользователем 12 современных бафов
исключены. Исходный JavaScript и счётчики mypers не подключаются.
Иконки предметов взяты из публичной базы Comeback.
Конфигурация предназначена для локального использования; production-развёртывание
требует отдельной настройки.
