# Каталог умений mypers

Запуск из корня проекта:

```powershell
uv run python -m tools.mypers.extract --cache .cache/mypers --output data/skills.json
```

Преобразователь читает три ранее сохранённых файла: `api_2__a=sb&k=yo.json`,
`lang.min.js`, `styles2-images.min.css`. JavaScript не исполняется.
Исходный код сайта и его спрайты в репозиторий не добавляются.
JSON5 используется только для чтения словаря переводов.

## Формат и ограничения

- `source_record` сохраняет исходные `states`, `lm`, `qc`, уровни и варианты
  без переименования и потери полей. Это ещё не готовые формулы калькулятора.
- `names` и `descriptions` содержат переводы, включая светлые/тёмные варианты.
  Подстановки вида `{tb}` остаются шаблонами.
- `sprite` содержит только координаты исходной иконки, не саму картинку.
  Для интерфейса нужны собственные иконки или разрешение на исходные.
- `source_sha256` позволяет установить, из каких локальных файлов получена выгрузка.
- В словаре есть повторные ключи. При экспорте берётся последнее значение,
  как в JavaScript; политика записана в JSON. По умолчанию `parse_language`
  отвергает повторы, разрешение включено явно только при экспорте.
- Классы ограничены 10 классами Comeback: Воин, Маг, Оборотень, Друид, Лучник,
  Жрец, Мистик, Страж, Шаман и Убийца. Общие записи без класса сохраняются;
  Призрак, Жнец и любые неизвестные классы исключаются. Наличие умения в современной
  базе mypers не подтверждает его наличие или числовые эффекты на Comeback 1.4.6.
  Поэтому весь каталог помечен `unverified_for_comeback`.

## Проверка текущего снимка

Из 462 записей API выгружены 409: 354 записи 10 классов и 55 общих.
53 записи других классов исключены. Названия найдены у 408 записей,
координаты иконок у 403; состояния есть у 238 записей.
Без названия осталась запись ID 619 (ключ перевода 10040).
Нет координат у ID 10053–10058. Пропуски не заменяются догадками.
220 записей помечены источником как баффы, 28 как дебаффы;
у остальных 161 тип не назначается автоматически.

Следующий шаг: сверить доступные умения и правила уровней с Comeback,
реализовать подстановку значений и обработчики типов состояний с тестами.
Экипировка и камни должны оставаться из comeback.pw, не из этого каталога.
