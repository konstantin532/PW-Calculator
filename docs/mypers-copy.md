# Копия интерфейса mypers для Comeback PW 1.4.6

Пользователь выбрал похожий внешний вид вместе с работающим калькулятором,
с сохранением версии Comeback PW 1.4.6. Технологии остаются прежними: Django,
обычный JavaScript и локальные JSON-каталоги. Основной образец — https://mypers.ru/.

## Что входит

- Компактный игровой интерфейс: баффы и дебаффы сверху, панель создания,
  загрузки и сохранения, окно характеристик слева, экипировка и сумка справа.
- По замечанию пользователя оформление исправлено: локальные оригинальные
  растровые рамки, портреты, силуэт, спрайты и Montserrat заменяют прежние SVG.
  Исходный JavaScript mypers не подключается. Чат, правые мини-окна, карты и
  указанные пользователем 12 современных бафов исключены из интерфейса.
- Ровно 10 классов по уточнению владельца: Воин, Маг, Оборотень, Друид,
  Лучник, Жрец, Мистик, Страж, Шаман, Убийца. Уровень, пол, имя, очки характеристик.
- Выбор подлинных предметов Comeback из доступного снимка базы; поиск,
  просмотр требований, заточка и камни с известными эффектами.
- Сохранение сборок в браузере, экспорт и импорт JSON, ссылка со сборкой.
- Адаптация для телефона, клавиатура, понятные состояния загрузки и ошибок.

## Ограничения данных

Современные предметы, карты, руны, перерождения и небеса mypers не подменяют
механику Comeback. Каталог восстанавливается только из уже собранных страниц.
Полнота каталога и непроверенные формулы отмечаются явно. Случайные свойства
предметов не выдаются за гарантированные: выбираются пользователем.
Выбранные баффы сохраняются, но неподключённые эффекты не меняют числа.

## План и проверка

1. Импорт снимка каталога и API (отдельные файлы от работающего сборщика).
2. Расчёт снаряжения, заточки, камней и проверка формата сборок.
3. Игровой интерфейс и все действия в браузере.
4. Проверки затронутых частей, полный набор один раз при интеграции,
   независимая проверка изменений и браузерные сценарии на ПК и телефоне.

Работа идёт в `codex/mypers-comeback-copy`. В `main` изменения не вливаются.
Репозиторий указан пользователем: https://github.com/konstantin532/PW-Calculator.
Его исходная ветка main содержит только README; локальная история сохраняется
в тематической ветке вместе с начальной историей GitHub, без перезаписи main.
