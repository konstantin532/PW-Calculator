# Объяснение характеристик и свойства экипировки

Одобренный этап: раскрытие здоровья, физической и магической атаки,
физической защиты, пяти защит стихий и их среднего; аудит и исправление
однозначных свойств из Comeback `/db/146/`. Дуэль и боевые скиллы не добавляются.
Формулы классов и порядок округлений сохраняются.

## Контракт движка

`getItemBonuses(entry, slot)` сохраняет прежние flat/ranges/atkSpeed/warnings
и добавляет:

- `contributions`: массив `{source, label, stat, value, percent, raw}`;
- source: `base`, `refine`, `stone`, `guaranteed`, `addon`;
- stat — итоговый поддержанный ключ; value — конечное число или пара
  для физической/магической атаки; percent обозначает процентные пункты;
- `unresolved`: `{source, label, reason, value:null}` для неподдержанного
  или неоднозначного источника. Неизвестное не отображается нулём.

Запись contributions появляется только при действительном применении прибавки
в итог getItemBonuses; постоянный бонус не дублируется старым выбором в addons.
Для неактивной вещи её записи остаются видны в объяснении как отключённые,
но не попадают в итоговые атрибуты или показатели.

`computeStats(...)` добавляет `explanations` без изменения остальных результатов.
Ключи: `hp`, `physAtk`, `magAtkRange`, `physDef`, `metal`, `wood`, `water`,
`fire`, `earth`, `magDef`.
Каждое объяснение:

```
{key, title, result, stages:[{label, expression, value}],
 sources:[{label, kind, active, reason, entries:[{label,stat,value,percent}]}],
 warnings:[string], note:string}
```

Стадии отражают действительную арифметику, включая промежуточные округления,
множители и ограничения. Последнее значение равно result и соответствующему
показателю computeStats. Для диапазонов value/result — пары чисел.
sources показывают собственные атрибуты и источники вещей, титулов и эффектов.
Источники и промежуточные итоги нельзя складывать повторно.
Неактивные вещи имеют active:false и причины. Неподдержанные свойства —
entries с value:null или предупреждения; не выдавать их за подтверждённый ноль.
Допустимо отдельное примечание о происхождении непроверенных базовых формул.

## Интерфейс

Общий модуль `createStatExplanationsUI() -> {render(explanations), open(key)}`
в `static/js/stat-explanations-ui.js`. Он сам связывает элементы
`[data-explain]` с объяснениями; в app.js render передаёт stats.explanations.
Нативные кнопки на нужных числах сохраняют существующие ID и текстовые значения.
Ключи в первой/второй половине STAT_ROWS соответствуют перечисленным выше.
Здоровье `#out-hp` остаётся доступно старым проверкам.

Диалог «Из чего получилась эта цифра» с заголовком показателя, итогом,
таблицей стадий и раскрываемыми источниками. Пять стихий и средняя защита
различаются. Нативное закрытие/Escape, доступный фокус, ограничение размера,
существующее позиционирование диалогов внутри iframe. Каждый калькулятор
содержит собственный модуль. Оформление тёмного металла и нефрита сохраняется.
Изменённые модули загружаются с общей версией `20261103-explanations`.
