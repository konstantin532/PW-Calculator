Контрольные действия

В браузере проверены переключение десяти классов, женский Мистик с портретом 10/f и мужской Страж с портретом 9/m. Контрольные значения сохранились: ЖС Воина 3195 и 4154 после бафа; «Сила духа» Мага 102 уровня — 15504; бонус титула «Здоровье» +100 даёт Мистику 2230 ЖС. Эти числа подтверждают сохранение поведения приложения при смене оформления.

Также проверены надевание нагрудника 4872 с заточкой +1, 32 ячейки сумки, сохранение и загрузка имени и экипировки, повторное открытие предмета из сумки, снятие вещей и надевание предмета на мобильном экране. Консоль браузера не показала ошибок или предупреждений.

Самостоятельный HTML и CSV читаются без интернета. В этом изменении не менялись движок расчётов, каталог и JavaScript приложения. Отчёт не заявляет полной сверки игровых формул с Comeback PW 1.4.6.
