# Бонусы предметов: сверка с mypers и Comeback146

Проверка 03.11.2026. Работающий оригинал используется для сверки порядка
операций. Наличие свойства и числовые параметры экипировки берутся из
Comeback `/db/146/`. Совпадение с mypers не заменяет отдельную сверку
с игровым клиентом Comeback1.4.6.

## Источник формул

Текущий [pwscripts.min.js?v26](https://mypers.ru/js/pwscripts.min.js?v26)
прочитан по HTTPS: HTTP200, 332744байта. Он полностью совпадает с локальным
`.cache/mypers/pwscripts.min.js`. SHA-256:
`365299f09ce10267b48f03693023875b5f601386fb4313e822b4b04baff04dea`.

Файл минифицирован и занимает одну строку. Ниже указаны имена методов
и смещения символов в сохранённом тексте, чтобы операцию можно было найти
без копирования всего исходника. `round` — функция округления оригинала,
`parseInt` отсекает дробную часть. Названия `dops` относятся к сумме бонусов
активного снаряжения, `ib` — к модификаторам эффектов.

| Показатель | Метод, смещение | Порядок применения |
| --- | --- | --- |
| Здоровье | `sd.ih`,261767 | Классовая база от уровня/выносливости + плоское здоровье + плоский эффект `zk`; затем общий множитель `1+(item co + fw − eh)/100`; окончательное округление |
| Мана | `sd.iz`,262437 | Классовая база + плоская мана; общий множитель `1+(item cc + vd − ef)/100`; окончательное округление |
| Физическая защита | `sd.qv`,268336 | Обычная формула защиты + округлённая поправка от суммы физзащиты снаряжения × `(item wf_eg + od + tb − va)/100`; отрицательный итог ограничивается нулём |
| Защита стихий | `sd.dd`,268928 | Аналогично для каждой из пяти стихий, с общим предметным `ab_gq_eg` и соответствующими эффектами стихии; среднее считается после отдельных итогов |
| Меткость | `sd.ev`,263723 | Классовая база от ловкости + плоские предметные/эффектные прибавки, затем общий процент предметов/эффектов |
| Уклонение | `sd.yp`,264355 | Классовая база от ловкости + плоское уклонение, затем общий процент предметов/эффектов |
| Передвижение | `sd.gy`,263132 | Базовая скорость класса + плоский эффект; затем общий процент; после него плоская скорость предметов; предел15м/с, вывод с одним десятичным знаком |
| Сокращение пения | `sd.xkw`,267595 | Сумма предметного `ci` и эффектов `re − xj`; предел100 и отсечение дробной части |

В оригинале сокращение пения хранится как положительная величина сокращения;
локальный `castTime` использует отрицательную поправку длительности. Например,
два кольца с−3% означают одну и ту же длительность при представлениях6% и−6%.
Знак интерфейса нужно согласовывать с существующей таблицей сравнения.

Словарь `.cache/mypers/lang.min.js:1` связывает `Channelling` и с «Время пения»
в показателях, и с «Время активации» в свойствах. Это объясняет потерю
однозначных алиасов: трактат [17654](https://comeback.pw/db/146/item/17654)
и камень [12637](https://comeback.pw/db/146/item/12637).

## Восстановление комплектов

Прежний импорт сохранял только названия частей в `item.set`. В проверенных
страницах источника уже были ID частей, название набора и числовые таблицы.
Поэтому старое ограничение «нет числового описания комплекта» описывало
потерю при импорте, а не отсутствие этих данных в Comeback146.

Примеры:

- [14927](https://comeback.pw/db/146/item/14927), «Сила безумного короля»:
  части14927/14933/14939/14945; две дают силу+10, четыре — уменьшение
  физического урона+3%.
- [25701](https://comeback.pw/db/146/item/25701), «Тень перерождения»:
  части25701/25702/25703/25704/25705/25713; две дают ПА+5, пять — ПЗ+10,
  шесть — ещё ПЗ+3. Порог6 не заменяет порог5.

У первого примера кеш
`f0d12e136b94af28ef17bfb7525fa6df8ed658bd.html`, у второго —
`9b5aecc0c6d49c3f19cd2752b5c093ff99b8651e.html`. Их SHA-256 сверены
с `source.html_sha256`. Идентичность подтверждает сохранённое происхождение,
не проверку чисел игровым клиентом.

Команда без сети:

```powershell
.venv\Scripts\python.exe -m tools.scrape.enrich_sets
```

Она проверяет SHA-256 всех страниц текущего каталога и точные адреса
`https://comeback.pw/db/146/item/<id>`, затем извлекает таблицы только из
`#suits-tab-pane`. Класс `table-union` встречается и у рецептов, поэтому поиск
по всей странице дал бы неверные пороги. Совпадающие описания объединяются
по отсортированным ID частей. Противоречие названия, состава или бонусов,
неверный порог, пустое описание и несоответствие хеша останавливают генерацию
до записи результата.

Единственный публикуемый файл — `data/catalog_sets.json`. `catalog_items.json`,
камни и файлы работающего сборщика остаются исходными снимками. API добавляет
`item.set_bonus` из этого справочника и сохраняет прежний `item.set`.
Снимок содержит166 уникальных наборов и582 числовых порога из803 таблиц.
В исходных списках817 ID частей:803 уже есть в каталоге,14 пока отсутствуют
в текущем снимке. Отсутствующие части не создаются искусственно и не
добавляются к числу надетых вещей.
При отсутствии отдельного справочника старый API продолжает работать;
нераспознанный набор сохраняет прежнее предупреждение. При изменении
первичного снимка справочник нужно сгенерировать заново: API проверяет
его источники на соответствие загруженным данным.

Поля `bonuses[].texts` сохраняют исходные описания. Они не превращают
нераспознанный условный эффект в нулевой или автоматически поддержанный бонус.
Бонусы набора применяет расчётный движок после проверки требований к частям.

## Границы доказательства

Общие операции оригинала можно воспроизвести и проверить на тех же входных
данных. Это ещё не независимая проверка всех формул сервера1.4.6. Современные
классы, карты, пассивные эффекты и дополнительные уровни заточки трактатов
из mypers не становятся частью Comeback автоматически. Неоднозначные единицы
сырой скорости оружия, условные срабатывания и непроверенные характеристики
требуют отдельного подтверждения; числовые значения для них не угадываются.
