Источник: подлинные сохранённые страницы Comeback. Файлы снимка независимы от продолжающего работать сборщика. Метаданные, URL и хеши страниц: data/catalog_meta.json и source каждой записи. Запуск

Дважды щёлкнуть Запустить сайт.bat в корне проекта. Команда альтернативного порта: .venv\Scripts\python.exe -m tools.serve --port 8002. Сайт использует локальные данные и изображения; сохранения находятся в браузере. Ссылки на сборки нужно открывать там, где доступна копия калькулятора.

Самостоятельный HTML и CSV работают без интернета. Публикация сайта и слияние в main не выполнялись.
